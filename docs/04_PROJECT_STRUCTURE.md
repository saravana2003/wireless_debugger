## 2. platformio.ini (planned)
Base it on Saro's config below. **Keep his settings.** Add `esp32_sim` and `native` envs in the phases that need them.
```ini
[env:esp32-s3-waveshare-43]
platform = espressif32
board = esp32-s3-devkitc-1
framework = arduino

board_build.f_cpu = 240000000L
board_build.f_flash = 80000000L

board_upload.flash_size = 8MB
board_build.arduino.memory_type = qio_opi
board_build.partitions = default_8MB.csv

build_flags =
    -DBOARD_HAS_PSRAM
    -DCORE_DEBUG_LEVEL=3
    -DLV_CONF_INCLUDE_SIMPLE
    -Isrc

lib_deps =
    lvgl/lvgl @ ^8.3.11
    lovyan03/LovyanGFX @ ^1.1.12

monitor_speed = 115200
monitor_filters = esp32_exception_decoder
```
Notes:
- The current `platformio.ini` on disk is the PlatformIO default (`board = waveshare_esp32_s3_touch_lcd_43`).
  **Replace it with the config above** in Phase 0 (confirm with Saro first), so the old project's known-good memory
  settings (N8R8, OPI PSRAM) are used.
- `.vscode/launch.json` is auto-generated by PlatformIO. Don't hand-edit it. The Cortex-Debug launch config for the
  RA8 goes in `docs/HOST_SETUP.md` (and later the RA8 project).

## 3. Coding conventions
- Module API in `lib/<mod>/<mod>.h`, prefixed functions or a namespace (`swd::`, `dap::`, `net::`, `ui::`, `arb::`).
- Hot path (SWD bit loop): `IRAM_ATTR`, no logging, no heap allocation, no `digitalWrite`.
- Tasks (proposal, confirm when implementing):
  | Task | Core | Priority | Notes |
  |---|---|---|---|
  | WiFi/lwIP | 0 | system | ESP-IDF default |
  | net_rx (TCP → queue) | 0 | high | |
  | dap_task (process packet → SWD) | 1 | highest app prio | owns the arbiter during packets |
  | ui_task (LVGL `lv_timer_handler`) | 1 | low | ~30 fps is enough |
- Inter-task: FreeRTOS queues of fixed-size packet buffers (allocated once at boot, PSRAM is ok for UI, but
  DAP buffers in internal RAM).
- Every module logs with `static const char *TAG = "<mod>";`.
- `.gitignore` must include `.pio/`, `include/secrets.h`, `.vscode/c_cpp_properties.json`, `.vscode/launch.json`.
